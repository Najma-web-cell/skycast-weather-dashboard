# 🌤️ SkyCast - Weather Dashboard

A modern, responsive React web application designed for real-time weather forecasting and location search. Features live temperature updates, atmospheric details, hourly forecast tracking, dynamic city search, and a 7-day weather outlook powered by Open-Meteo APIs.

---

## ✨ Features

- **🔍 Advanced City Search:** Search and find real-time weather conditions for any city globally using Geocoding integration.
- **🌡️ Live Weather Insights:** View accurate current temperatures, feels-like metrics, wind speed, humidity, and atmospheric pressure.
- **⏰ Hourly Forecast Tracker:** Interactive hourly breakdown to monitor temperature fluctuations throughout the day.
- **📅 7-Day Weather Outlook:** Multi-day extended forecast displaying daily high/low temperatures and weather conditions.
- **📱 Fully Responsive:** Seamless visual layout optimized across mobile, tablet, and desktop screens.
- **⚡ Fast & Lightweight:** Built using Vite for instant load times with zero API key dependencies.

---

## 🛠️ Tech Stack

- **Frontend:** React.js (Hooks, State Management)
- **Build Tool:** Vite
- **HTTP Client:** Axios / Fetch API
- **Styling:** Tailwind CSS / Custom CSS3
- **Data Source:** [Open-Meteo API](https://open-meteo.com/) (Weather & Geocoding)
- **Version Control:** Git & GitHub
